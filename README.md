# FTSBC — Telegram Mini App магазина FORCE TRADE SERVICE

Витрина алкогольного магазина внутри Telegram (@ftsbcbot): подтверждение
возраста → категория → страна → корзина (с минимальным заказом по позиции) →
оформление заказа. Каталог собран из прайс-листа (86 позиций, 3 категории:
Вино, Виски, Водка).

Задеплоено на **Vercel**, из **этого** GitHub-репозитория, одним проектом:
фронтенд (статика) + бэкенд бота (serverless-функция) на одном домене
`https://ftsbc.vercel.app`. Автодеплой при каждом пуше в ветку `main`.

## Из чего состоит

| Путь | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js`, `data.js` | сама витрина (статика) |
| `images/` | фото товаров, `<id>.jpg` — id смотрите в `products_reference.csv` |
| `build_data.py` | пересобирает `data.js` из Excel-прайса + подставляет картинки |
| `products_reference.csv` | справочник id → товар (для называния файлов картинок) |
| `api/webhook.py` | бэкенд бота — serverless-функция, принимает вебхуки от Telegram |

Бэкенд без внешних библиотек (только стандартная библиотека Python) —
специально, чтобы не тянуть лишние зависимости в serverless-окружение.

## Переменные окружения (Vercel → Project → Settings → Environment Variables)

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен бота из @BotFather |
| `ADMIN_CHAT_ID` | chat_id, куда пересылать оформленные заказы |
| `MINI_APP_URL` | `https://ftsbc.vercel.app` (адрес этого же деплоя) |
| `WEBHOOK_SECRET` | случайная строка — проверяется в заголовке запроса от Telegram, чтобы никто посторонний не мог слать боту фейковые события на этот публичный URL |

После изменения переменных нужен **Redeploy** (Vercel → Deployments → ⋯ →
Redeploy) — на лету новые значения не подхватываются.

## Как это работает

1. Telegram шлёт HTTPS POST на `https://ftsbc.vercel.app/api/webhook` при
   каждом сообщении/событии бота (режим **webhook**, не polling — на
   serverless-хостинге держать постоянный процесс с long polling нельзя).
2. `/start` → бот присылает reply-кнопку «🛍 Открыть витрину» со ссылкой на
   `MINI_APP_URL`.
3. Покупатель проходит сценарий в Mini App и жмёт «Отправить заказ» →
   `Telegram.WebApp.sendData()` → Telegram сам доставляет это боту как
   служебное сообщение с полем `web_app_data`.
4. `api/webhook.py` разбирает заказ, пересылает читаемым текстом в
   `ADMIN_CHAT_ID`, отвечает покупателю подтверждением.
5. `/id` — присылает ID текущего чата (удобно, чтобы узнать `ADMIN_CHAT_ID`).

## Как задеплоить заново / обновить

Ничего вручную собирать не нужно — просто:
```bash
git add -A
git commit -m "описание изменений"
git push
```
Vercel сам подхватит пуш в `main` и передеплоит за ~30–60 секунд.

## Где смотреть логи

Vercel → проект `ftsbc` → вкладка **Logs** (или Deployments → выбрать
деплой → Functions → `api/webhook`) — там видны и обычные `print()`, и ошибки
из `api/webhook.py`.

## Если бот молчит — куда смотреть

1. **Vercel → Logs** — приходят ли вообще запросы на `/api/webhook`?
   - Не приходят совсем → проблема в вебхуке Telegram (см. пункт 2)
   - Приходят, но с ошибкой 401 → не совпадает `WEBHOOK_SECRET`
   - Приходят, ошибка 500/исключение в логе → смотреть текст ошибки
2. **Проверить вебхук на стороне Telegram:**
   ```bash
   curl "https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo"
   ```
   Поле `url` должно быть `https://ftsbc.vercel.app/api/webhook`,
   `pending_update_count` не должен расти бесконечно, `last_error_message`
   (если есть) укажет на причину.
3. **Проверить, что функция вообще жива:** открыть в браузере
   `https://ftsbc.vercel.app/api/webhook` (GET) — должен вернуться JSON
   `{"ok": true, ...}` с флагами, какие переменные окружения заданы.
4. **Переменные окружения не заданы/не применились** — самая частая причина.
   Проверить в Vercel → Settings → Environment Variables, что все 4
   переменные на месте, и сделать Redeploy.

## Обновление ассортимента / картинок

1. Обновите Excel-прайс (лист «Общий», колонки: Категория, Страна, Бренд,
   Название, Емкость, Минимальный заказ, Цена).
2. Кладите фото товаров в `images/<id>.jpg` (id — из `products_reference.csv`).
3. Запустите:
   ```bash
   python3 build_data.py "Прайс для телеграма.xlsx"
   ```
   Скрипт пересоберёт `data.js` и подставит найденные картинки.
4. Закоммитьте и запушьте — Vercel передеплоит автоматически.

## Что нужно проверить и заменить

- **Валюта** — по умолчанию тенге (`₸`), меняется в `CURRENCY` в `data.js`.
- **Ссылки на оферту и политику конфиденциальности** — на экране
  подтверждения возраста сейчас заглушки в `app.js` (`link-offer` /
  `link-privacy`) — вставьте настоящие адреса.

## Локальная разработка

```bash
python3 -m http.server 8080
```
Открыть `http://localhost:8080` — вне Telegram витрина сама переключается в
тестовый режим (упрощённая навигация, но вся логика та же). Бэкенд
(`api/webhook.py`) локально таким способом не проверить — он рассчитан на
среду Vercel; для локальной отладки бота используйте `python3 -m http.server`
для фронтенда и тестируйте API-логику отдельными вызовами функций.
