# Telegram Mini App — FORCE TRADE SERVICE

Витрина алкогольного магазина внутри Telegram: подтверждение возраста →
категория → страна → корзина (с минимальным заказом по позиции) → оформление
заказа. Собрана из прайс-листа «Прайс для телеграма.xlsx» (86 позиций,
3 категории: Вино, Виски, Водка).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка всех экранов |
| `style.css` | стили, тема берётся из Telegram (`--tg-theme-*`), с запасной палитрой |
| `app.js` | вся логика: навигация, корзина, валидация, отправка заказа |
| `data.js` | каталог товаров (сгенерирован из Excel) |
| `build_data.py` | скрипт для пересборки `data.js` при обновлении прайса |
| `bot/` | бэкенд бота @ftsbcbot — принимает заказы из Mini App (см. `bot/README.md`) |

## Как проверить локально

```bash
cd miniapp
python3 -m http.server 8080
```

Открыть `http://localhost:8080` в браузере — вне Telegram приложение само
переключается в тестовый режим (свои кнопки «Назад», без нативных Telegram
BackButton/MainButton, но вся логика работает одинаково).

## Как подключить к реальному боту (нужно сделать вам)

1. **Захостить файлы по HTTPS.** Подойдёт GitHub Pages, Netlify, Vercel,
   Cloudflare Pages или собственный сервер. Telegram принимает только
   `https://` адреса для Mini App.
2. **Бот уже создан:** @ftsbcbot. Бэкенд для него лежит в `bot/` — он
   присылает reply-кнопку «🛍 Открыть витрину» и принимает оформленные заказы
   через `Telegram.WebApp.sendData()`. Подробности запуска — в
   [`bot/README.md`](bot/README.md).
3. Как только адрес будет готов, впишите его в `bot/.env` как `MINI_APP_URL`
   и перезапустите бота — кнопка в `/start` заработает.
4. **Почему именно reply-кнопка, а не Menu Button/инлайн-кнопка:** только
   через `web_app` reply-keyboard button Mini App может вызвать
   `Telegram.WebApp.sendData()`, и Telegram сам доставит заказ в бота как
   служебное сообщение `web_app_data` — это уже реализовано в `bot/bot.py`.
   Если решите переключиться на Menu Button/инлайн-кнопку, `sendData` станет
   недоступен, и приём заказа нужно будет переделать на `fetch()` из
   `app.js` к отдельному HTTP-эндпоинту — скажите, и я донастрою.

## Что нужно проверить и заменить перед запуском

- **Валюта.** По умолчанию используется тенге (`₸`) — в прайсе валюта не
  указана явно. Если это другая валюта, поменяйте `CURRENCY` в начале
  `data.js`.
- **Страна для категории «Водка».** В исходном Excel в колонке «Страна» для
  всех позиций водки стоит значение «Водка» (не страна). Я заменил это на
  «Россия» как наиболее вероятный вариант — **проверьте и поправьте**, если
  неверно (в `data.js`, поле `country`, или через `build_data.py`).
- **Ссылки на оферту и политику конфиденциальности.** Сейчас на экране
  подтверждения возраста это заглушки (`https://example.com/offer` и
  `.../privacy` в `app.js`, поиск `link-offer` / `link-privacy`) — вставьте
  реальные ссылки.
- **Телефон/способ связи в форме заказа** — сейчас это просто текстовые поля,
  без серверной валидации номера. При необходимости добавьте маску/проверку.

## Логика минимального заказа

Колонка «Минимальный заказ» из прайса используется как минимальное количество
**по каждой позиции**: при добавлении товара в корзину количество сразу
выставляется равным минимальному (например, 6 бутылок), кнопка «−» ниже этого
порога убирает позицию из корзины целиком. Общего минимума по сумме заказа
в прайсе не было — если он нужен, скажите, добавлю проверку на экране корзины.

## Обновление ассортимента

1. Обновите Excel-прайс (лист должен называться «Общий», порядок колонок:
   Категория, Страна, Бренд, Название, Емкость, Минимальный заказ, Цена).
2. Запустите:
   ```bash
   python3 build_data.py "Прайс для телеграма.xlsx"
   ```
3. Скопируйте получившийся `data.js` в папку приложения.
4. Если появилась новая категория или страна — добавьте для неё
   иконку/флаг в `CATEGORY_META` / `COUNTRY_META` в `data.js`.
